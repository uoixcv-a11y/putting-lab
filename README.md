# 퍼팅 랩

- `index.html` — 실시간 퍼팅: 폰 카메라로 퍼팅을 보면서 볼 스피드·예상 거리·방향을 소리로 알려줘요.
- `analyze.html` — 찍은 영상 분석: 스윙 궤도·템포, 퍼팅 여러 개 자동 분석.

영상과 카메라 화면은 폰 안에서만 처리되고 어디에도 올라가지 않아요.

## 올리는 방법 (GitHub Pages, 무료)

1. github.com 에서 계정을 만들어요.
2. 오른쪽 위 **+** → **New repository** → 이름은 `putting-lab`, **Public** 선택 → **Create repository**.
3. 화면의 **uploading an existing file** 을 눌러 이 폴더의 파일을 모두 끌어다 놓고 → **Commit changes**.
4. 저장소의 **Settings** → 왼쪽 **Pages** → Source는 **Deploy from a branch**, Branch는 **main** / **(root)** → **Save**.
5. 1~2분 뒤 `https://아이디.github.io/putting-lab/` 로 들어가면 돼요.
6. 폰 Chrome에서 열고 메뉴 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.

## 쓰는 법

1. 삼각대에 폰을 고정해 공을 위에서 내려다보게 해요. 폰 긴 쪽을 퍼팅 방향으로 두고 공 앞 1m까지 화면에 들어오게요. 화면 왼쪽 위에 나오는 기울기를 1° 안쪽으로 맞추면 가장 정확해요.
2. **카메라 켜기** → 출발 자리에 놓인 공을 한 번 눌러요 → 매트 선 위에 두 점을 눌러 목표선을 그어요.
3. **측정 시작**. 공을 놓고 멈추면 "띵", 퍼팅하면 공이 화면 끝까지 간 뒤 결과를 읽어줘요. 볼 스피드, 예상 거리, 방향과 함께 미끄러진 거리와 구름 효율(구르기 시작할 때 남은 속도, 보통 71%)도 보여줘요.
4. 설정에서 목표 거리, 그린 빠르기, 읽어줄 내용, 카메라 프레임(60/30fps)을 바꿀 수 있어요.
